# NNNN. Título conciso da decisão

- **Data:** YYYY-MM-DD
- **Status:** Proposto | Aceito | Substituído por [NNNN](./NNNN-titulo.md) | Deprecado
- **Decisores:** nome ou squad
- **Tags:** persistência | api | observabilidade | segurança | ...

## Contexto

Qual problema, restrição ou força nos colocou nessa decisão? Que coisas precisam ser verdadeiras para essa decisão fazer sentido?

Manter curto: 1–3 parágrafos. Se precisar de mais, provavelmente são dois ADRs.

## Decisão

A decisão em si, na voz ativa: "Vamos fazer X."

Se houve alternativas consideradas, listá-las brevemente:

- **Opção A (escolhida):** descrição em uma frase.
- **Opção B:** descrição em uma frase. Rejeitada porque [...].
- **Opção C:** descrição em uma frase. Rejeitada porque [...].
